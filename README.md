# ENIGMA-9

A single-page Caesar cipher tool with a rotating cipher wheel. Bilingual: English and Indonesian.

## Run

Just open `index.html` in a browser. No install, no server needed or u can use this "https://toroosnc.github.io/cryptography/".

## How it works

Drag the **shift slider** — that's your key. The inner wheel rotates to match it visually.

Type your message, hit **Encrypt** or **Decrypt**, result shows up below. Copy button included.

Example, shift = 3:
```
abc -> def
```

## Important

To decrypt something, you need the **same shift key** used to encrypt it. Wrong key = garbage output.

## Language

Toggle **ID / EN** buttons top right of the controls to switch the whole interface.
